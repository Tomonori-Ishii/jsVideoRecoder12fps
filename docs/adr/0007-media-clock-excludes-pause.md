# ADR-0007: 時刻は一時停止を除いた録画時間（メディアクロック）で管理する

- 状態: 承認
- 関連: 要件 F-024、F-004、F-003、Issue #2、#3、#28

## 決定
- メディアクロック `t`（ミリ秒）は録画中だけ進む。一時停止中は進まない。再開すると、停止前の値から続く。
- 映像の枠番号は `slot = floor(t × 12 / 1000)`。同じ枠に複数のフレームが来た場合は最初の 1 枚だけを使う（撮影が間に合わないフレームは落とす、F-021）。
- 音声のサンプル位置は、録画中に受け取ったサンプルの累計（48kHz）とする。一時停止中に受け取った音声は捨てる。
- 経過時間の表示（F-004）も `t` を使う。

## 結果
- 一時停止をはさんでも、映像と音声の時刻は 0 から詰めて続く（F-024）。
- 音声と映像の累計がずれる場合は、停止時の長さの差として Issue #28 のテストで計測する。

## 追記（実装で決めたこと）
- メディアクロックは、最初の映像フレームを受け取った時点で 0 から始まる。開始ボタンから最初のフレームまでの時間は録画に含めない（録画の先頭に映像がない時間を作らないため）。
- 一時停止中に届いたフレームと音声は捨てる。一時停止の前に届いたフレームの扱いは変えない。
