# ADR-0005: 停止時に mp4 を多重化する（メインプロセス、再符号化なし）

- 状態: 承認
- 関連: 要件 F-029、F-030、F-036、Issue #32、#33、#34

## 決定
- 多重化には `mp4-muxer` 5.2.2（純 JavaScript、H.264 と Opus に対応）をメインプロセスで使う。
- 中間ファイルの各レコードを読み、映像は枠番号順に 1/12 秒ごとのサンプルとして追加する。サンプルの時刻は枠番号から決める（CFR）。
- 書き込み先は `screen_<YYYYMMDD_HHMMSS>.mp4.partial`。完了したら `.mp4` に改名する。失敗時は `.partial` を削除し、中間ファイルは残す（要件 F-029）。
- 進み具合（F-036）は、多重化したサンプルの時間 ÷ 録画全体の時間。約 0.5 秒ごとに通知する。
- 同名のファイルは上書きする（要件 7.6、9.3）。

## 結果
- 多重化は再符号化を含まない。停止時の時間は、中間データの読み出しと書き込みの量で決まる（Issue #32 で計測）。
- `mp4-muxer` は非フラグメント形式のため、サンプル表（約 86,400 件 / 2 時間）をメモリに保持する。この量は数 MB 程度で、3 分分の保持とは別の問題として扱う。
