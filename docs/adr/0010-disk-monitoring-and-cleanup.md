# ADR-0010: 空き容量の監視と起動時の掃除

- 状態: 承認（閾値は要件 9.1 の仮の値）
- 関連: 要件 F-033、F-037、F-038、Issue #35、#36、#37

## 決定
- 空き容量は `fs.promises.statfs`（Node.js 18.15 以上）で取得する。
- 録画開始前: 空き容量が 3GB 未満なら開始しない（仮の値）。
- 録画中: 30 秒ごとに確認する。空き容量 < 現在の中間データ量 + 0.5GB なら録画を止め、中間ファイルを残す。画面に「空き容量が不足したため録画を止めました」と中間ファイルの絶対パスを表示する（F-033、F-037）。
- 通常停止後: 空き容量 ≥ 中間データ量 + 0.2GB のときだけ mp4 を作る。足りない場合は mp4 を作らず中間ファイルを残す。
- 状態ファイル `state.json`（録画フォルダ直下）に、録画 ID、状態（`recording` など）、中間ファイルの場所を書く。
- 起動時: `state.json` があれば、その録画フォルダと `.partial` を削除する（F-037、F-038）。正常に保存完了した録画は、`state.json` を削除済みなので対象外。
- 閾値は定数（`electron/recording/config.cjs`）に集める。変更は 9.1 の確定後に行う。
