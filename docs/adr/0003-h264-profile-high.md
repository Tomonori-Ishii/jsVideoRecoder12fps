# ADR-0003: H.264 のプロファイルは High（avc1.640028）を使う

- 状態: 承認（要件書 F-022 の補足。要件書の本文は変更しない）
- 関連: ADR-0002、ADR-0006、Issue #25

## 背景
要件 F-022 はコーデックを「H.264（`avc1`）」と定め、プロファイルを指定しない。ADR-0002 の調査で、Electron の WebCodecs は Baseline 系を非対応、High を対応と確認した。

## 決定
- プロファイル High、レベル 4.0（`avc1.640028`）を使う。
- 符号化方式（CAVLC か CABAC か）は PPS で決まる。スキップフレームの合成（ADR-0006）は、PPS の `entropy_coding_mode_flag` が 0（CAVLC）の場合だけ行う。CABAC が使われていた場合は、スキップフレームを符号化しない方式にフォールバックし、そのことを記録する（Issue #27 の受け入れ条件に影響するため feature-list に記す）。

## 理由
- Electron の Chromium で実際に動く唯一の H.264 設定である。
- 要件の「H.264（avc1）」を満たす。

## 結果
- 再生互換性は High プロファイルの一般的な再生環境（ffprobe、主要なプレイヤー）で確認する。
