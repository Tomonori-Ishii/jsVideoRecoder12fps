# 機能リスト

要件定義書の機能要件（F-001〜F-038）と、対応する Issue、設計判断（ADR）、進捗の一覧です。

進捗の凡例:
- **開発完了**: 実装し、計画したテストの確認が取れた（備考に残りの未確認を書く）
- **未完了**: 実装していない、または計画したテストが未実施・不合格
- **保留**: 実装は終えたが、このマシンや環境では確認できない、または判断待ち（備考に理由）

最終更新: テスト実行時点（単体 39、静的 18、E2E 41 件すべて合格）。計画と結果は各 Issue のコメントを参照。
